# Matrix-Calculator
This is a calculator designed for performing matrix algebra calculations

# Operations
1. Create a matrix (Zero matrix, ones matrix, identity matrix, constant matrix, custom matrix)
2. View matrices
3. Delete or clear matrices
4. Element-wise addition
5. Element-wise subtraction
6. Element-wise multiplication
7. Scalar multiplication
8. Determinant
9. Transpose
10. Finding an element in i<sup>th</sup> row and j<sup>th</sup> column
11. Multiplicative inverse of the matrix
